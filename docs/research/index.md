# Research

## Documents

* [CLI subscription bridges](cli-subscription-bridges.md) - Whether dax-editor can let users drive their own ChatGPT, Claude or Gemini subscriptions through the official CLIs, which flags make that possible, and where the vendor terms draw the line.
* [Creator editing styles as engine templates](creator-editing-styles.md) - Sixteen creator and format editing styles reduced to measurable parameters, mapped onto the engine's presets, with the engine gaps ranked by how many styles need them.
* [Cut intelligence](cut-intelligence.md) - Open-source state of the art for making good automatic cuts, with a recommended cut-engine design, default parameters, cut-quality metrics and the pitfalls behind each rule.
* [Cut quality field notes](cut-quality-field-notes.md) - Real failures users report from automatic cutting tools (clipped words, breaths, music, drift, VFR, clicks), how others fixed them, what packages/core/src/cuts.ts already handles, and the concrete change or test each one needs, plus licence-checked datasets for a cut-quality eval.
* [Embedded local LLM via llama-server](embedded-local-llm.md) - Which free, open-weight model and llama.cpp runtime the desktop app could download and run locally for tool-calling video edits, with file names, sizes, licences, flags and pitfalls.
* [FFmpeg animation recipes](ffmpeg-animation-recipes.md) - Tested FFmpeg filter recipes for overlays, zoom, music and sound-effect mixing, B-roll layers, speed ramps and text animation that the renderer does not have yet, with the gotchas found while testing them.
* [Industry video templates](industry-video-templates.md) - Per-industry recipes for what a good video looks like, a template schema that expresses them, and three worked examples for applying them to uploaded footage.
* [Landscape, risks and gaps](landscape.md) - Survey of existing open-source video editors, MCP servers and renderers, with the licensing and technical risks that shaped the plan.
* [MCP server design for dax-editor](mcp-server-design.md) - Recommends a loopback Streamable HTTP MCP server with a per-launch bearer token, Host and Origin checks, and a stdio shim for Claude Desktop, built on the v2 MCP TypeScript SDK and checked by runnable tests.
* [Open-source radar and intake policy](open-source-radar.md) - Twenty open-source projects for AI video editing, creator tools and generators, checked against their LICENSE files and commit dates, plus the autonomous intake policy a scout agent must follow before adopting a tool.
* [OpenChatCut learnings](openchatcut-learnings.md) - Ideas we take from OpenChatCut, a conversational AI video editor under AGPL-3.0, plus where dax-editor will adopt them or differ.
* [Open-source animation and generation options](oss-animation-and-generation.md) - Ranks free, redistributable tools for motion graphics, sketch animation, characters, lip sync and AI video by licence and feasibility, and proposes a plugin contract that returns transparent media for dax-editor to composite.
* [Open-source effects and transitions](oss-effects-and-transitions.md) - Which Premiere, After Effects and CapCut style effects can run as pure FFmpeg filters, which need a separate plugin process, and which open-source licences rule options out.
* [Open-source voice and audio for video](oss-voice-and-audio.md) - Free, offline text-to-speech, voice cloning, speech enhancement, source separation and CC0-safe sound sources for dax-editor, with licence verdicts checked against the intake rules.
* [Plugin architecture for dax-editor](plugin-architecture.md) - Recommends separate-process plugins that speak JSON-RPC over stdio, described by a plugin.json manifest with declared permissions, hashed downloads and data-only template packs, based on how other extensible tools handle trust.
* [Screen, webcam and microphone recording for the desktop app](screen-and-webcam-recording.md) - Compares FFmpeg, webview and native-helper ways to record screen, webcam, microphone and system audio in a Tauri 2 app on macOS, Windows and Linux (X11 and Wayland), with licence checks of OBS, Cap, Screenity, Kap and BlackHole and an engine plan.
* [Local speech-to-text with word timestamps](speech-to-text.md) - Options for an offline, cross-platform speech-to-text step that returns word-level timestamps for transcript display, captions and filler or silence cuts, with the flags, model URLs and pitfalls checked against primary sources where possible.
* [Tauri sidecar packaging for a Node engine and FFmpeg](tauri-sidecar-packaging.md) - Plan for shipping a Tauri 2 desktop app with a bundled Node.js engine and LGPL FFmpeg on macOS, Windows and Linux without asking users to install Node, with verified config, commands, licence rules and pitfalls.
* [Timeline UI patterns](timeline-ui-patterns.md) - Recommends a plain React timeline on pointer events, engine-owned state and an FFmpeg-fed proxy preview, and records which permissive timeline and drag libraries were checked and rejected.
